# HorizonForge

**Global Multi-Market Alpha Prediction System**

Проект по созданию интеллектуальной системы прогнозирования и поиска альфа-сигналов на глобальных финансовых рынках с использованием машинного обучения и внешних факторов (включая климат).

## Цель проекта

Создать единую платформу, которая анализирует и прогнозирует поведение различных классов активов:
- Криптовалюта
- Акции (186 компаний из S&P 500 и тематических секторов)
- Влияние климатических факторов на рынки

## Текущие результаты

### Глобальная модель с климатическими факторами
- **Средний AUC**: **0.7381**
- **Walk-Forward Backtest**:
  - Доходность: **+110–120%**
  - Максимальная просадка: **-8.79%**

### Покрытие
- 186 акций
- Темы: сельское хозяйство, удобрения, вода и опреснение, экологические компании, телекоммуникации, энергетика

## Технологии
- Python, LightGBM, pandas_ta, yfinance, CCXT
- Интеграция климатических данных (температура, осадки, засуха)
